# Rocket Show Documentation

Rocket Show is a system to automate and play shows including audio, video, lighting (e.g. DMX) and MIDI on Raspberry Pi
devices.

The complete user documentation, with screenshots of every screen, is on
[rocketshow.net/docs](https://rocketshow.net/docs).

- [Getting Started](getting-started/getting-started.md), a community guide to installing Rocket Show on a Raspberry Pi
